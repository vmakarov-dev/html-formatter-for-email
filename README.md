# HTML Formatter

Локальный офлайн-форматтер HTML-кода — заточен под вёрстку email-писем
(таблицы в таблицах, условные MSO/Outlook-комментарии, инлайн-стили).
Расставляет отступы, не трогая содержимое, плюс отдельные проверки на
целостность тегов, пустые атрибуты и русскую типографику.

**Живой инструмент:** https://vmakarov-dev.github.io/html-formatter-for-email/

## Возможности

- Форматирование HTML с сохранением исходного содержимого — меняются
  только отступы/переносы строк, не сам контент.
- Форматирование CSS внутри `<style>`.
- Диагностика незакрытых тегов, тегов с пропущенным родителем
  (например, `<td>` без `<tr>`) и «лишних» закрывающих тегов — с
  подсказками «Добавить?»/«Удалить?» прямо в браузере.
- Проверка пустых атрибутов (`src=""`, `href=""` и т.п.).
- Очистка служебной разметки email-конструкторов (`<tbody>`,
  `class="esd-text"`).
- Типограф: неразрывные пробелы, «ёлочки» вместо прямых кавычек, длинное
  тире вместо дефиса между словами — только там, где рядом есть
  кириллица.
- Два уровня сжатия готового кода (только отступы / отступы и переносы
  строк) с живым подсчётом веса файла.

## Структура проекта

```
src/            TypeScript-ядро форматтера (парсер, рендерер, типограф, CSS)
bin/cli.ts       CLI-обёртка
web/index.html   Самодостаточный браузерный интерфейс (открывается и по file://)
tests/           Тесты (node:test)
scripts/         Вспомогательные скрипты сборки
```

`web/index.html` не подключает `src/*.ts` напрямую — браузеры блокируют
ES-модули по `file://`. Вместо этого `npm run build:web` компилирует
`src/*.ts` в `dist/` и склеивает результат в один самодостаточный
`web/formatter.bundle.js` (см. `scripts/build-web-bundle.mjs`).

## Установка и запуск

```bash
npm install
```

**Веб-интерфейс** (без сборки — просто открыть файл):

```bash
open web/index.html
```

Если менялся код в `src/`, сначала пересоберите бандл:

```bash
npm run build:web
```

**CLI:**

```bash
npm run build
node dist/bin/cli.js input.html -o output.html
# либо через stdin:
cat input.html | node dist/bin/cli.js > output.html
```

Флаги: `--collapse-outlook-comments` (схлопывать `<!--[if ...]>` в одну
строку), `--no-typografy` (выключить типограф).

**Тесты:**

```bash
npm test
```

## Разработка

- `npm run build` — компиляция `src/`+`bin/` в `dist/` (используется как
  Node-библиотека/CLI).
- `npm run build:web` — то же самое плюс пересборка
  `web/formatter.bundle.js`.
- `npm run lint` — ESLint по `src/`, `bin/`, `tests/`, `scripts/` и
  JS-файлам в `web/js/`.
- `npm test` — тесты форматтера (`node:test`).

CI (`.github/workflows/pages.yml`) на каждый пуш в `main` гоняет `npm
test`, затем собирает и публикует `web/` на GitHub Pages.
